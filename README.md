# Excel Analytics Portfolio — Nicola Maluleke

Six Microsoft Excel analytics projects demonstrating advanced formulas,
VBA automation, data analysis and business reporting.

## Workbooks

1. Reconciliation — Invoice and payment analysis, balances and exceptions.
2. Inventory — Stock, demand and reorder calculations.
3. Service SLA — Response times, resolution metrics and compliance.
4. Commercial Performance — Revenue, margins and commercial reporting.
5. Customer Retention — Retention, churn and customer metrics.
6. Operations Quality — Delivery performance, defects and quality reporting.

All six files are available in the [workbooks](workbooks/) directory.

The three XLSM workbooks contain VBA automation and are intended for
use with Microsoft Excel.
